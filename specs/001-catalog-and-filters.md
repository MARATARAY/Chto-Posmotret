# Базовый каталог карточек, поиск и фильтры

## Для кого и зачем
Для посетителя страницы «Кадр», который хочет быстро найти фильм, сериал или мультфильм по названию и категории и сразу увидеть количество подходящих карточек.

## Что должно быть
- Каталог с заранее заданным локальным набором карточек: не менее двух фильмов, двух сериалов и двух мультфильмов для проверки поиска и фильтров.
- Каждая карточка содержит название и явно указанную категорию. Название остаётся читаемым, даже если занимает несколько строк.
- Поле поиска с видимой подписью «Поиск по названию» и подсказкой «Введите название».
- Поиск по вхождению части названия, без учёта регистра. Пробелы в начале и конце запроса игнорируются; запрос из одних пробелов считается пустым.
- Список обновляется при вводе, без отправки формы, перезагрузки страницы и отдельной кнопки поиска.
- Четыре фильтра: «Все», «Фильмы», «Сериалы», «Мультфильмы». Одновременно выбран один фильтр, по умолчанию — «Все».
- Поиск и категория работают совместно: карточка видна, только если подходит под оба условия.
- Смена категории сохраняет поисковый запрос. Очистка поля сохраняет выбранную категорию.
- Счётчик «Найдено: N», где N — количество показанных карточек после применения поиска и категории. При первом открытии он равен общему количеству карточек каталога.
- При отсутствии совпадений показать «Ничего не найдено» и пояснение «Измените название или выберите другую категорию». Счётчик показывает 0, сами элементы поиска и фильтрации остаются доступны.
- Порядок карточек при фильтрации сохраняется.
- Поиск и фильтры доступны с клавиатуры; у активного фильтра есть различимое оформление и программно определяемое состояние. Изменения счётчика доступны скринридеру без переноса фокуса.
- Каталог работает при локальном открытии index.html двойным щелчком.

## Примеры
- В тестовом каталоге есть по две карточки каждой категории. При пустом поиске и фильтре «Все» видны шесть карточек, счётчик — «Найдено: 6».
- Нажатие «Сериалы» оставляет две карточки сериалов, счётчик — «Найдено: 2».
- В каталоге есть фильм «Начало». Запрос «  НАЧ  » с фильтром «Фильмы» находит эту карточку; остальные карточки показываются только при совпадении с тем же запросом.
- Если «Начало» — единственная карточка с таким названием, запрос «Начало» и фильтр «Мультфильмы» дают пустой результат и «Найдено: 0».
- После очистки поиска с выбранным фильтром «Мультфильмы» снова видны все мультфильмы. Нажатие «Все» возвращает весь каталог.
-Если за прошлый месяц просмотрено 0 → выводится нейтральная строка: «В прошлом месяце записей не было».
-Если за текущий месяц просмотрено 0 → отображается заглушка «В этом месяце вы ещё ничего не отметили как просмотренное», а кнопка «Скопировать отчёт» неактивна (disabled) или копирует базовую заглушку.
-🎬 Мои итоги просмотра за Ноябрь 2026:
Всего просмотрено: 5 (на 2 больше, чем в прошлом месяце)
Топ категорий:
1. Фильмы — 3
2. Сериалы — 1
3. Мультфильмы — 1


## Ограничения
- До сообщения пользователя «делай» создавать и редактировать только этот файл спецификации; код и ресурсы не менять.
- Имя файла specs/001-catalog-and-filters.md задано пользователем явно и используется независимо от нумерации существующих спецификаций.
- Источник каталога локальный; сервер, внешнее API и сетевой поиск фильмов не нужны.
- Поиск проверяет только название, без поиска по описанию, исправления опечаток и транслитерации.
- Не добавлять новые категории, сортировку, пагинацию, избранное и другие функции в рамках этой задачи.
- Существующие пользовательские записи не удалять и не перезаписывать стартовым набором. Уже имеющиеся функции добавления, изменения статуса и сохранения записей должны продолжать работать; после изменения состава каталога результаты и счётчик пересчитываются.
- Сохранить существующее оформление, фон и кинодекор. На ширине 375 px не должно быть горизонтальной прокрутки.
- Сохранять поисковый запрос и выбранную категорию между перезагрузками не требуется.

## Готово, когда
- При открытии index.html двойным щелчком видны карточки и корректный начальный счётчик.
- Поиск находит полное название и его часть, игнорирует регистр и крайние пробелы; очистка запроса возвращает карточки выбранной категории.
- Каждый из четырёх фильтров показывает подходящие карточки, активный фильтр визуально и программно обозначен.
- Совместная работа поиска и категории проверена как на совпадениях, так и на пустом результате.
- При каждом изменении запроса, категории или состава каталога счётчик равен числу видимых карточек.
- Пустой результат сопровождается сообщением, счётчиком 0 и возможностью изменить условия.
- Клавиатурой можно перейти в поиск, ввести запрос, выбрать фильтр и увидеть контур фокуса; обновление результатов не уводит фокус.
- На ширине 375 px поиск, фильтры, счётчик и карточки помещаются без горизонтальной прокрутки.
- Если на странице уже есть пользовательские записи и статусы, они сохраняются после обновления страницы. Проверка избранного из общих правил проекта к этой функции не применяется: его добавление не входит в задачу.
- После реализации README.md описывает каталог, поиск, фильтры, счётчик и последовательность ручной проверки. Отчёт перечисляет изменённые файлы, выполненные проверки и то, что осталось непроверенным.
