# Автозаполнение данных по названию из Кинопоиска

## Для кого и зачем
Для пользователя «Кадра», который вводит название в форме добавления и хочет выбрать нужный фильм, сериал или мультфильм, чтобы не заполнять год, рейтинг и длительность вручную.

## Что должно быть
- Использовать существующее поле «Название» формы добавления. Поиск в уже сохранённом каталоге не менять.
- После ввода минимум трёх символов без крайних пробелов и паузы 500 мс показывать до пяти вариантов. При более коротком запросе закрывать список и не отправлять запросы. Не искать во время незавершённого ввода через IME.
- Для вариантов показывать название, год и категорию, чтобы различать одноимённые произведения. Пользователь явно выбирает вариант; первый результат автоматически не выбирать.
- Показывать состояния «Ищем…», «Ничего не найдено. Заполните данные вручную» и «Не удалось получить данные. Заполните данные вручную». Ошибки, отсутствие интернета, лимит запросов или ненастроенный доступ не мешают ручному добавлению.
- При выборе заполнить название, категорию, год, рейтинг Кинопоиска и длительность, если они известны и допустимы. Отобразить подпись «Данные Кинопоиска через ПоискКино» и ссылку на соответствующую страницу kinopoisk.ru по проверенному числовому ID.
- Предлагаемый источник — сторонний сервис ПоискКино (ранее kinopoisk.dev), а не официальный API Кинопоиска. Документация: https://api.poiskkino.dev/documentation, описание: https://poiskkino.dev/. Для интеграции требуется ключ этого провайдера; доступность и подходящий тариф проверяются перед подключением, подписки автоматически не оформлять.
- Получать именно рейтинг Кинопоиска. Не подменять его IMDb и не менять личную оценку. Допустимый рейтинг 0–10 округлять до одной цифры после точки; отсутствующий рейтинг не превращать в 0.0.
- Для фильмов и мультфильмов длительность — минуты; для сериалов — число сезонов. Не подставлять длительность эпизода вместо сезонов. Мультсериал относить к «Сериалам»; полнометражную анимацию — к «Мультфильмам». Неизвестный тип не угадывать и не добавлять новые категории.
- При отсутствии или недопустимости данных оставить соответствующее поле пустым и предложить заполнить вручную. При выборе другого результата очистить старые импортированные значения, отсутствующие у нового результата.
- Все заполненные поля можно исправлять. Статус, дата просмотра, личная оценка и комментарий сохраняют введённые пользователем значения. Описание фильма не подставлять в личные впечатления.
- Если после выбора изменено название, снять привязку к источнику и очистить только неотредактированные автоматически заполненные поля. Ручные изменения не терять. При новом явном выборе варианта заменить метаданные выбранным произведением.
- Поздние ответы предыдущих запросов и запросов деталей не должны менять новое название, выбранный вариант, закрытую или уже отправленную форму. Очистка поля, Escape и успешное добавление закрывают подсказки и отменяют актуальность запросов.
- Данные попадают в каталог только после нажатия «Добавить в каталог» и обычной проверки формы. Сохранить имеющиеся ID и данные пользователя; новым записям можно добавить необязательные поля источника и ID Кинопоиска.
- Подсказки доступны с клавиатуры: стрелки выбирают вариант, Enter подтверждает его без отправки формы, Escape закрывает список. Использовать доступный combobox/listbox с состояниями expanded, active descendant и сообщениями загрузки; фокус остаётся в поле. Кнопки и варианты не меньше 44 px, ширина 375 px без горизонтальной прокрутки.

## Примеры
- Ввести «Начало»: после паузы появляются варианты с годами. Выбрать нужный фильм — поля заполняются полученными данными; личная оценка и комментарий не меняются. Рейтинг не фиксируется в коде: он может изменяться у источника.
- Ввести название с несколькими экранизациями: выбрать нужную по году. В каталог не добавляется ничего до подтверждения формы.
- Выбрать сериал без сведений о сезонах: поле длительности остаётся пустым, пользователь указывает сезоны вручную.
- Выбрать фильм A, затем фильм B без рейтинга: рейтинг A не переносится на B.
- Быстро заменить «Начало» на «Шерлок»: запоздавший ответ для «Начало» не появляется в подсказках и не заполняет форму.
- Нет интернета, ключа или исчерпан лимит: показана подсказка о ручном заполнении, введённые данные остаются, ручное добавление работает.
- Открыть index.html двойным щелчком: ручная форма продолжает работать, вместо сетевых запросов показано пояснение «Автозаполнение доступно на опубликованном сайте».

## Ограничения
- Пока пользователь не написал «делай» для этой функции, менять только эту спецификацию; код, ресурсы, README.md и настройки публикации не менять.
- По запросу пользователя для этой функции вводится исключение из запрета внешних ресурсов: разрешены запросы названия и выбранного ID через серверный обработчик сайта к выбранному API. Историю просмотров, заметки, личные оценки, избранное и весь каталог не отправлять.
- Предлагаемая реализация для обсуждавшегося Vercel — серверная JavaScript-функция без сторонних библиотек. Ключ хранить в переменной окружения Vercel, не в браузере, localStorage, Git или URL. Настройка требует доступа к проекту Vercel и ключа провайдера; их наличие сейчас не подтверждено.
- Не разбирать HTML страниц Кинопоиска и не обходить ограничения сайта. Сервер обращается только к фиксированному адресу API, проверяет длину запроса, ID, таймаут и структуру ответа, ограничивает частоту обращений и повторные запросы. Произвольные URL от клиента не загружать. Данные API выводить как текст.
- Кратковременно кешировать одинаковые запросы, не сохранять полную историю поисков. Ошибки провайдера показывать без ключей и служебных данных. Не запускать бесконечные повторные запросы.
- Автозаполнение работает на опубликованном сайте при настроенной серверной функции. Открытие через file:// сохраняет локальную функциональность без автозаполнения. Если провайдер не настроен, не имитировать результаты локальным набором.
- Не добавлять постеры, актёров, рекомендации, синхронизацию каталога или фоновое обновление сохранённых карточек в рамках этой функции.
- Обновление сайта не переносит localStorage с локального файла на домен Vercel; старые сохранения не удалять и не обещать автоматический перенос.

## Готово, когда
- На опубликованном сайте настроен ключ, проверены реальные поиск и получение деталей выбранного результата; ключ отсутствует в исходниках, ответах сервера и запросах браузера к провайдеру.
- Подтверждены задержка и минимальная длина запроса, выбор среди одноимённых произведений, отмена подсказок, очистка формы и игнорирование устаревших ответов, включая ответы после добавления.
- Проверены все три категории, отсутствующие значения, минуты и сезоны, смена результата и ручные исправления. Личная оценка и впечатления не заменяются данными API.
- Ошибки сети, 401/403, 429, таймаут и повреждённый ответ не ломают форму. Без ключа и через file:// доступно ручное добавление.
- Добавленная запись сохраняется после обновления, находится поиском и категориями; избранное, статусы, оценки, удаление, отмена удаления и итоги месяца продолжают работать.
- Проверены клавиатура, доступные сообщения и ширина 375 px. Изолированные тесты используют фиктивные ответы API; реальная проверка выполняется отдельно после настройки доступа.
- После реализации обновлён README.md: источник, настройка окружения, работа через Vercel и ручной режим, проверки и их результаты. Создан Git-коммит с относящимися к задаче файлами.
