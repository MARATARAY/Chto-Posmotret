    
# AGENTS.md — КиноМания

## О проекте
Скучно дома? Не знаешь, чем себя занять? Конечно же посмотри фильмы, которые вдохновят, взбудоражат или расслабят!
Файлы: `index.html` — разметка, `styles.css` — вид, `script.js` — логика.
Требования к функциям — в папке `specs/`. Описание для людей — в `README.md`.

## Правила
- Только HTML, CSS и JavaScript в этой папке. Без npm, фреймворков и сторонних библиотек.
- Личные списки, избранное и историю просмотров храни в браузере (`localStorage`). Никакие пользовательские данные в интернет не отправляй.
- Для автозаполнения названия, года, длительности, постера и рейтингов Кинопоиска и IMDb разрешены GET-запросы к API Кинопоиска (`https://poiskkino.dev` или `https://kinopoiskapiunofficial.tech`) с заголовком `X-API-KEY` и загрузка постеров по HTTPS.
- Поля, заполненные автоматически из API (год, рейтинг КП, рейтинг IMDb, длительность), защищены от ручного редактирования (`readonly`).
- Формат данных: год выхода — 4 цифры (`2024`), рейтинг — число с одной цифрой после точки (`8.4` или `—`), длительность — в минутах или сезонах (`120 мин`, `2 сезона`), категории строго из списка: `Фильм`, `Сериал`, `Мультфильм`.
- В отчёте за месяц рейтинг категорий формируется из трёх категорий (`Фильм`, `Сериал`, `Мультфильм`) по убыванию количества просмотренного.
- Интерфейс на русском языке, подписи короткие и понятные.
- Кнопки и поля высотой не меньше `44px`. На экране шириной `375px` страница работает без горизонтальной прокрутки (кнопки внутри карточек располагаются удобно для нажатия, не выходя за края экрана).

- После тестов обязательно делать Git-коммит.

## Новая функция
- Каждую новую функцию начинай с файла `specs/NNN-nazvanie.md`. `NNN` — следующий номер: `001`, `002`, `003`... Название — латиницей через дефис.
- Разделы файла: `Для кого и зачем`; `Что должно быть`; `Примеры`; `Ограничения`; `Готово, когда`.

## Как проверить
- Открыть `index.html` двойным щелчком в браузере.
- Ввести название фильма в поиск (например, «Начало») → подтягиваются название, постер, год и рейтинги КП / IMDb, поля недоступны для ручной правки.
- Нажать фильтр «Сериалы» или ввести название в поиск по каталогу → в списке остались только подходящие карточки, счётчик найденного обновился.
- Нажать «В избранное» на карточке → статус сохранился, после нажатия `F5` карточка остаётся в избранном.
- Проверить отображение в режиме мобильного экрана шириной `375px` без горизонтальной прокрутки и с кнопками не меньше `44px`.
